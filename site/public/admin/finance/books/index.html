자동 분류가 틀린 거래만 오른쪽에서 계정을 바꾸면 됩니다. 노란 줄은 규칙에 안 걸려 "기타"로 간 거래입니다.

결산서 설정

회계 처리 방식 — 장부의 수입 1건은 차변 예금(또는 현금) / 대변 수익계정, 지출 1건은 차변 비용계정 / 대변 예금(또는 현금)으로 자동 분개합니다. 결제수단이 "현금"이면 101 현금, 그 밖은 102 보통예금으로 봅니다. "예정·예산" 거래는 분개하지 않습니다. 이전 연도까지의 누적 결과는 다음 연도 기초 순자산으로 자동 이월됩니다.
서식은 비영리 단체 결산에서 흔히 쓰는 재무상태표·운영성과표 구성을 따랐습니다. 공식 결산이나 외부 제출 전에는 회계 전문가의 검토를 권합니다.
