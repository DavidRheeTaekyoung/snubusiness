호텔 계약 때문에 RFP에 반드시 넣을 조건

  • 행사장 입장·설치는 당일 15:00부터. 무대 설치·리허설 시간 확보 대책 제출 요청 (조기 설치는 호텔 협의 필요)
  • 외부 AV 사용 시 호텔 파트너 Encore 지도·감독 및 감독비 발생 가능 — 견적에서 호텔 관련 외부 비용 구분
  • 외부 대행사 정보는 행사 최소 60일 전 호텔 서면 통보, 외부 설치물·전기는 호텔/Encore 사전 승인
  • 계약 만찬 13만원/인, 예산 가정 16만원/인 — 메뉴·변경 서면 합의 전까지 16만원을 계약 확정가로 설명하지 않음
  • 대행사에는 호텔 계약 확정과 필수 기술 제약만 전달. 호텔 전체 계약서·개인정보는 별도 승인 없이 배포 금지
