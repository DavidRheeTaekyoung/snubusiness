출처 연결 방법

세 곳 모두 무료이고, 각 사이트에서 직접 발급받은 키를 Cloudflare에 등록하면 위 버튼이 작동합니다. 키는 채팅이나 이 페이지에 붙여넣지 말고 터미널에서 직접 입력해 주세요.
  1. 네이버 검색 API: developers.naver.com → Application 등록 → 사용 API "검색" 선택 → Client ID와 Client Secret 발급. 하루 25,000회.
    npx wrangler pages secret put NAVER_CLIENT_ID --project-name snubusiness
    npx wrangler pages secret put NAVER_CLIENT_SECRET --project-name snubusiness
  2. OpenDART: opendart.fss.or.kr → 인증키 신청. 하루 20,000회.
    npx wrangler pages secret put DART_API_KEY --project-name snubusiness
  3. 열린국회정보: open.assembly.go.kr → 인증키 신청.
    npx wrangler pages secret put ASSEMBLY_API_KEY --project-name snubusiness
등록 후에는 배포를 한 번 다시 해야 키가 반영됩니다 (에이전트에게 "배포해" 하면 됩니다). 학교 쪽 SNU Biz 앱 자료는 명단 탭의 "자료 붙여넣기"로 넣습니다.
원칙: 공개된 직함과 출처만 기록하고 연락처·사생활은 모으지 않습니다. 명단은 깃과 공개 페이지에 올리지 않습니다.
