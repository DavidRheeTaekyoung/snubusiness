## 1. 기존 사이트 분석 — 서울대학교 상과대학 총동창회 (sangdae.com)

### 1.1 개요
- 회원: 경영대학·경제학부·자유전공학부(경영/경제 전공) 졸업생, 약 25,000명. 1949년 발족, 약 70년 역사.
- 사무국: 서울대학교 58동 121-1호, Tel 02-761-2278.
- 플랫폼: 그누보드 계열 국산 CMS 기반의 전형적인 국내 동창회 사이트.

### 1.2 정보구조 (메인 메뉴)
1. **동창회 소개** — 인사말, 연혁(1949~현재), 회칙, 임원, 사무국 안내
2. **공지 및 행사** — 공지사항, 동창회 소식, 행사 갤러리
3. **동창회비** — 회비 안내, 납부 계좌 (국민은행 계좌 직접 노출)
4. **동문** — 동문 경조사, 동문 기업
5. **동창회보 및 자료** — SangdaeNews, 서울상대 70년사
6. **참여마당** — 자유게시판 성격
7. 우측 퀵메뉴 — SangdaeNews, 향상의 탑, 향상장학회, 서울상대 70년사, 서울대 총동창회

### 1.3 홈 화면 구성
- 히어로: 동문 단체사진 슬라이드 + "경영대학·경제학부 동문과 함께하는 서울대학교 상과대학 총동창회" 카피
- 3단 리스트: 공지사항 / 동창회 소식 / 동문경조사
- 동창회비 · 총동창회 발자취 · 사무국 안내 배너 3개
- 행사 갤러리 슬라이드, 동문기업 슬라이드
- 푸터: 주소, 전화, 사업자등록번호, 관련 사이트 링크

### 1.4 운영 콘텐츠의 특징 (우리 사이트 콘텐츠 설계에 참고)
- **정례 행사**: 정기총회 겸 신년하례회(1월), 상대인 산행대회 및 어린이 사생대회(5월 5일), 사은의 밤(5월 스승의 날), 골프대회(상·하반기), 바둑대회(가을), 회장단회의·정기이사회(12월), 장학금 전달식(학기별)
- **경조사** 게시 형식: "홍길동 동문(경영 24회) 본인상/모친상/빙모상" — 학과 + 회차 표기
- **회칙 구조**: 총칙 / 회원 / 임원(회장 1, 부회장 50 내외, 감사 2, 이사 100 이상, 사무국장) / 회의(총회·회장단회의·이사회) / 재정(입회비·연회비·평생회비·분담금·찬조금, 회계연도 12/1~11/30)
- **상(賞) 문화**: 뭉치자상(최다 참석 기수), 돕자상(최다 협찬 지부), 빛내자상(연회비 완납 지부)
- **장학**: 재단법인 향상장학회(1991) 분리 운영

9. **Recent Alumni(GOLD)** — 졸업 10년 이내 젊은 동문 전용 트랙.

### 2.3 디자인 · 톤앤매너
- **색**: 각 학교의 아이덴티티 컬러(HBS crimson, Stanford cardinal, Wharton navy/blue, Booth maroon, LBS navy)를 절제된 화이트 스페이스 위에 사용. 컬러 남용 없이 사진과 타이포그래피로 품격 표현.
- **타이포**: 세리프 헤드라인(전통·권위) + 산세리프 본문(가독성) 조합이 다수.
- **사진**: 캠퍼스 건축, 동문 모임의 "따뜻하지만 정돈된" 장면. 스톡 느낌 배제.
- **카피**: 1인칭 소속감("here for you — for life", "Continue your journey"). 짧고 확신에 찬 문장.
- **구조**: 히어로 → 통계 → 핵심 서비스 카드 → 이벤트 → 스토리 → 기부 CTA → 푸터의 정석 흐름.
- **모바일**: 전부 반응형. 햄버거 메뉴 + 대형 터치 타깃.

## 4. 기술 리서치 요약
- **호스팅**: Cloudflare Pages (GitHub 연동 자동 배포, 무료 HTTPS, 글로벌 CDN). 도메인 snubusiness.com은 이미 Cloudflare 네임서버 사용 중 → 커스텀 도메인 연결만으로 완료.
- **동적 기능**: Pages Functions (서버리스) + D1 (SQLite 호환 DB). 초기 트래픽 규모에서 무료 티어로 충분.
- **정적 우선**: 빌드 도구 없이 HTML/CSS/JS로 구성 → 배포 실패 가능성 최소화, 어느 개발자든 유지보수 가능.
- **회원 인증(P3 후보)**: Cloudflare Access 이메일 OTP(사무국 소수 관리자용) / 자체 이메일 매직링크(동문용). 졸업생 명부 대조는 사무국 검수 워크플로로.
- **결제(P4 후보)**: 토스페이먼츠 또는 KG이니시스. 기부금 영수증(국세청 연계)은 별도 검토.
